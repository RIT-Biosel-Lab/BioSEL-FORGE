# BioSEL-FORGE (Fabrication, Operation, Rigs, Guides, and Extensions)

This repo, the BioSEL-FORGE is the catch all repository for anything related to the release of Data in Brief + Zenodo release of the dataset; and reflects current updates / versions of what BioSEL is working on toward public hosting, especially with respect to *soft robotics actuator*.

The included information is but not limited to are: Arduino codes, legacy schematics, Sensors Specs that may have changed, python scripts that do not meet the scope that BioSEL-PULSE does or was not included originally, guides, and any extensions needed where new information was gathered since the release that do not warrant major updates. The information will also be updated on Zenodo in batches. 

**This repository is also intended to be where inquiries are are to be directed that is related to anything from the Data in Brief + Zenodo Release**.
